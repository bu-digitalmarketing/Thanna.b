### ❌ หาไม่เจอ — ต้องเติมเอง

**อาชีพ, การศึกษา, ผลงาน, ทักษะ, ประวัติการทำงาน, อีเมล** — ไม่มีข้อมูลเปิดเผยสาธารณะ
บนเว็บเลย ไม่มี LinkedIn, ไม่มีเว็บส่วนตัว, ไม่มีข่าวหรือบทความ

- โปรไฟล์ **Facebook ดึงไม่ได้** — ตอบว่า *"This content isn't available at the moment"*
  (ตั้งค่าไม่ให้คนที่ไม่ได้ล็อกอินเห็น)
- โปรไฟล์ **Instagram เป็นรูปภาพล้วน** ไม่มีข้อความบอกอาชีพหรือการศึกษา

ผมไม่เดาหรือแต่งข้อมูลพวกนี้ให้ครับ — ทุกจุดที่ต้องเติมมีคำว่า `TODO` กำกับไว้ใน
`assets/js/data.js` และ **ชื่อทักษะ / ผลงาน / ประวัติการทำงาน ที่เห็นในเว็บตอนนี้
เป็นตัวอย่างล้วน ๆ** ใส่ไว้ให้เห็นว่าหน้าตาเป็นยังไงเฉย ๆ

## วิธีแก้ข้อมูล

เปิดไฟล์ **`assets/js/data.js`** ไฟล์เดียวจบ — ข้อความทุกอันเขียนเป็นคู่ไทย/อังกฤษ:

```js
name: { th: "ชื่อภาษาไทย", en: "Thannapat Boonsinpuripat" }
```

ในไฟล์นั้นแบ่งเป็น 6 ส่วน:

| ส่วน | แก้อะไร |
|---|---|
| `profile` | ชื่อ ชื่อเล่น ตราปีเกิด คำโปรย (สลับได้หลายบรรทัด) แนะนำตัว รูป ตัวเลขเด่น |
| `marquee` | คำที่วิ่งผ่านเป็นแถบใต้ส่วนหัว |
| `portfolio` | การ์ดผลงาน — เพิ่ม/ลบได้ไม่จำกัด |
| `skills` | แถบทักษะ (`level` = 0–100) |
| `experience` | ไทม์ไลน์ประสบการณ์/การศึกษา เรียงใหม่→เก่า |
| `links` | ปุ่มโซเชียลท้ายเว็บ (เว้น `url` ว่าง = ไม่แสดงปุ่มนั้น) |

### จุดที่ควรแก้ก่อนเพื่อน

1. **ชื่อภาษาไทย** — ตอนนี้ยังเป็นอักษรโรมันอยู่ทั้งสองภาษา เพราะถอดกลับเป็นไทยได้หลายแบบ
2. **`taglines`** — คำโปรยที่พิมพ์ทีละตัวใต้ชื่อ
3. **`bio`** — ย่อหน้าแนะนำตัว
4. **รูปโปรไฟล์** — ตอนนี้ขึ้นเป็นตัวย่อ `TB`

### ใส่รูป

วางไฟล์รูปไว้ใน `assets/img/` แล้วอ้างถึงใน `data.js`:

```js
avatar: "assets/img/profile.jpg"     // รูปโปรไฟล์
image:  "assets/img/work1.jpg"       // รูปในการ์ดผลงาน
```

ถ้าไม่ใส่รูป เว็บจะใช้ตัวอักษรย่อของชื่อ และ emoji + พื้นไล่สีแทนโดยอัตโนมัติ

### เปลี่ยนสี

แก้ตัวแปร `--c1` ถึง `--c5` ที่หัวไฟล์ `assets/css/style.css` — สีทั้งเว็บเปลี่ยนตามทันที

## วิธีเปิดดู

ดับเบิลคลิก `index.html` ได้เลย หรือถ้าอยากรันเป็นเซิร์ฟเวอร์:

```bash
ruby -run -e httpd . -p 4321
```

แล้วเปิด http://localhost:4321

| 4 | ชื่อไล่สีเลื่อนไปมาตลอดเวลา |
| 5 | คำโปรยพิมพ์ทีละตัวอักษร แล้วลบ วนไปบรรทัดถัดไป |
| 6 | รูปโปรไฟล์เอียงตามเมาส์แบบ 3 มิติ + วงแหวนเปลี่ยนสีวนไป |
| 7 | ตราปีเกิด `๑๙๙๖ 🌈` ลอยขึ้นลงเบา ๆ |
| 8 | ตัวเลขเด่นนับขึ้นจาก 0 ตอนเลื่อนมาเห็น |
| 9 | แถบคำวิ่งไม่มีที่สิ้นสุด (หยุดเมื่อเอาเมาส์ไปชี้) |
| 10 | การ์ดผลงานเอียงตามเมาส์ + มีจุดแสงวิ่งตาม + emoji เด้ง |
| 11 | การ์ดโผล่ขึ้นทีละใบไล่กัน |
| 12 | แถบทักษะเติมความยาว + เปอร์เซ็นต์นับขึ้น + มีแสงวิ่งในแถบ |
| 13 | เส้นไทม์ไลน์ค่อย ๆ ลากลงมา แล้วแต่ละรายการเลื่อนเข้าทีละอัน |
| 14 | หัวข้อแต่ละส่วนมีเส้นขีดใต้ยืดออก |
| 15 | เมนูด้านบนไฮไลต์หัวข้อที่กำลังอ่านอยู่ |
| 16 | ปุ่มมีแสงกวาดผ่านตอนเอาเมาส์ไปชี้ |
| 17 | ปุ่มโซเชียลเด้งขึ้นทีละอัน + ไอคอนสั่นตอนชี้ |

ทั้งหมดปิดอัตโนมัติถ้าผู้ใช้ตั้งค่า **"ลดการเคลื่อนไหว" (reduce motion)** ไว้ในเครื่อง

## ฟีเจอร์อื่น

- ปุ่มสลับ **ไทย ⇄ อังกฤษ** (จำค่าที่เลือกไว้)
- ปุ่มสลับ **โหมดสว่าง ⇄ มืด** (เริ่มต้นตามการตั้งค่าของเครื่อง)
- รองรับมือถือ / แท็บเล็ต / จอคอม

## โครงสร้างไฟล์

```
index.html            โครงหน้าเว็บ
assets/css/style.css  หน้าตา + จานสี + อนิเมชัน
assets/js/data.js     ← แก้ข้อมูลที่นี่
assets/js/main.js     ตัวสร้างเนื้อหา + อนิเมชัน (ปกติไม่ต้องแตะ)
assets/img/           วางรูปที่นี่
```
